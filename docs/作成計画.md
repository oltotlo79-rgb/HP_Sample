## 4. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| Cloudflare Workers の制約で Three.js / GSAP がエッジ実行で動かない | サンプル B/C 表現が再現不可 | クライアントコンポーネント化 (`'use client'`) でブラウザ側のみ実行。SSR は静的 HTML を返す。 |
| 画像生成の品質バラつき | 視覚的訴求の低下 | 同一プロンプト枝雛形を用意し、サンプル単位で世界観を統一。各画像にネガティブプロンプトを併記。 |
| 3 サンプルで世界観が混ざる | 差別化が弱まる | サンプルごとに `layout.tsx` でカラートークンとフォントをスコープし、共通コンポーネントは敢えて使い回さない |
| Lighthouse 性能低下 (重アニメ) | 90 未達 | 重い演出は IntersectionObserver で遅延・サスペンド。3D は code-split。 |
| PPT 由来テキストの解釈ミス | 製品事実誤り | `src/content/product.ts` に集約し PR レビュー必須項目とする |
| 商用利用フォントの誤用 | 法務リスク | Google Fonts / オープンソースに限定。Reckless Neue 等は採用しない (代替: Fraunces, Schibsted Grotesk) |

## 5. 命名規則

- ブランチ: `feat/sample-a-hero` , `chore/setup-cloudflare`
- コミット: Conventional Commits (`feat:` `fix:` `chore:` `docs:` `refactor:`)
- ファイル: コンポーネントは `PascalCase.tsx` 、ユーティリティは `kebab-case.ts`
- 画像: `s{a|b|c}-{section}-{purpose}.{webp|png|svg}` 例: `sa-hero-leaf-bg.webp`

## 10. メインページ (`/`) 仕様

確定事項 D7 に基づき、メインページは **ニュートラル (オフホワイト + 深緑アクセント)** で統一する。3 サンプルの世界観を侵食しない中立的なステージ。

- 背景: `#FAFAFA` / セクション差分 `#F0EFE9`
- 文字色: `#1B1F1B`
- アクセント色: `#2F5233` (深緑) ボタン・タグ・下線
- フォント: Noto Sans JP (本文) + Fraunces (見出し) のみ
- レイアウト:
  - ヘッダー: 左にロゴ、右に「資料 (電話番号)」リンク
  - センターヒーロー: 「3 つのデザインサンプルを比較する」コピー + 短いリード
  - 中央 3 カード (A/B/C): 各カードに名前 / コンセプト / 1 枚のキービジュアル / 「サンプルを開く →」ボタン
  - フッター: 会社情報・電話 03-6891-1010・住所
- アニメーション: 最小限。カードのホバーで影が伸びる程度。
- カード用画像は各サンプルの代表 OG 画像 (A-16 / B-18 / C-14) を流用可能。

```
+-------------------------------------------+
|  QuickCRM (logo)                     03-… |
+-------------------------------------------+
|                                           |
|     3 つのデザインサンプルを比較する         |
|     リード: 同じ製品を、異なる世界観で。      |
|                                           |
|  +-------+  +-------+  +-------+          |
|  |   A   |  |   B   |  |   C   |          |
|  | Forest|  | Glass |  |Editor.|          |
|  | open →|  | open →|  | open →|          |
|  +-------+  +-------+  +-------+          |
|                                           |
+-------------------------------------------+
|  会社情報 / 03-6891-1010 / 住所            |

```
